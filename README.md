# FitLog

FitLog is a modern web application designed to help users track, organize, and manage their daily workout routines and fitness goals efficiently.

## Description

FitLog provides a simple and intuitive user interface to explore workout routines, filter exercises based on specific criteria, and save personal fitness plans. Built with a focus on responsiveness and performance, the platform allows seamless management of workout schedules across all devices.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API

## Key Features

- Dynamic Workout Cards: Displays comprehensive exercise details including targets, duration, and intensity levels.
- Sorting and Filtering: Allows users to easily filter and sort workout routines according to target muscle groups and duration.
- Plan Management: Enables users to add, update, or remove workout routines from their personalized fitness plan.
- Persistent Data Storage: Automatically saves custom workout selections to local storage for uninterrupted usage across sessions.
- Responsive Layout: Optimized user interface across mobile, tablet, and desktop viewports.
